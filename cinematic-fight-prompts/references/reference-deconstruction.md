# 参考战斗视频拆解

目标是提取可迁移的导演规律，而不是复述剧情或模仿具体角色。

## 取样

观看条件允许时，至少记录开场、首次交锋、一次反转、最大命中和尾帧五个节点。对每个节点写清：双方位置、动作起点、攻击路径、接触点、受击位移、镜头运动、特效来源、环境结果。无法访问参考片时明确说明，不凭链接或缩略图猜测。

## 六层导演指纹

1. 动作语法：重心先移到哪里，武器怎样带动肩胯，攻击结束后身体落到什么可继续动作的姿态。帅气姿态必须同时具备清楚轮廓、明确力线和下一动作出口。
2. 镜头语法：每个镜头只承担一种主要任务。跟拍交代速度，侧向平移展示攻击路径，急推放大接触，环绕重建空间，短暂远景展示规模。
3. 节奏曲线：标记每秒为读势、加速、接触、释放或重置。高速段之间保留0.2–0.6秒的可读窗口；这是运动中的构图稳定，不是人物停住或慢动作。
4. 特效系统：把特效绑定到身体、武器、敌人和环境四个来源。每项区分前兆、运动轨迹、接触爆发、余波残留，避免只在画面上覆盖发光粒子。
5. 环境因果：风压、尘土、碎石、植被、云层、积水和光照应按距离依次响应攻击。环境反应延迟、方向和规模要与力量一致。
6. 信息控制：任何时刻优先保证主体轮廓、攻击路径和接触点中的两项清楚。特效密度最高时，用明暗、冷暖或景深分层，而不是继续增加颜色。

## 输出导演指纹

用一页内容回答：

- 这条片最常用的三种动作结构是什么？
- 速度如何在一段内变化？峰值落在哪里？
- 镜头如何在贴身、侧向和规模展示之间轮换？
- 哪些特效负责预告、导向、命中和留痕？
- 环境如何证明攻击真正发生在这个空间里？
- 哪三条规律最适合迁移到当前角色、武器和场景？

不要把“电影级、震撼、丝滑、炸裂”等感受词当作结论；每个结论必须对应可见动作或镜头证据。
